# 設計書との対応

v0.2.0では、参照版v0.7.0の28系統をRustの登録規則として実装しています。倍率・付加項・指数などの登録プロファイルは75種類です。各プロファイルの係数を変えて問題を生成するため、75は出題数ではありません。参照版の全プロファイル、全242問との完全互換、任意のブロック合成は対象に含めません。

|設計項目|実装|
|---|---|
|厳密計算|任意精度のBigInt、既約BigRational。数学的判定に浮動小数点を使用しない|
|Recipe|構成、接続、パラメータ、種、規則・乱数版を保存。登録構成と一致する、最大4ブロックのDAGのみ採用|
|内容ID|数学的な式の加算・乗算順を正規化し、規則版と問題IRからハッシュを計算|
|旧版との互換|初版の7系統は規則版1.0と内容IDを保持。追加21系統は規則版1.1、参照規則は共に0.7.0|
|ProblemIR|自然数の添字、有理数の値、束縛変数、初期条件、漸化式、一般項、非零条件を区別。連立の2数列も同じIRで表現|
|DerivationIR|補助数列、式変形、理由、説明文。画面とTeXが同じ式を参照|
|難易度|表示する式と初期条件から前向きに解法を検出。教育スコアのLv区間は0〜3、4〜7、8〜12、13〜18、19〜25。B/R/A/T/P/Uの内訳も記録|
|品質|表示漸化式の式要素44以下、分数深さ2以下、加算構造8以下、係数次数2以下、発見3以下。新規生成は数値コスト8以下で、一般項に未評価の総和・総積を残さない|
|Lean|4.19.0、mathlib固定。初期条件、全項の漸化式、一意性、IRの非零条件を独立モジュールで検証|
|監査|必須4定理と標準公理のみの依存を確認。終了コード、環境・問題・証明のハッシュを対応付け|
|要求管理|ID、候補と時間の上限、同時検証1件、中止・タイムアウト時の子プロセス終了|
|画面|準備状況、Lv・型、進行・経過時間、中止、個別の方針・解答、TeX保存、Recipe保存と再現。連立は両方の一般項を表示|
|古い結果|要求トークンとIDで処理中の要求を区別。失敗・中止時は表示中の問題を保持|
|オフライン|画面と数式資産はRust実行ファイルに同梱。初回準備後の実行に通信とPythonは不要|
|偏り|型を先に選び、直近40問の頻度で重みを下げる。逆数型の基礎重み2。履歴を保存|
|測定|各Lv10問の時間分布を記録するベンチマークスクリプト。成功・失敗、環境、系統、採点、各ハッシュ、要求時間とLean時間を保存|

難易度のLvは参照版の教育スコアから決めます。操作などの内訳の合計値は別の診断値であり、学習者の正答率から推定した難易度ではありません。品質の構造次数は登録形の解法検出で判定し、任意式を対象とする一般的な次数解析器は実装していません。連立の数式の大きさは各漸化式で計測します。

数値コストは表示式・初期条件と、登録検出器が算出する中間値から測定し、各型の登録範囲で適用します。新規生成は上限8を適用します。規則版1.0の保存済み重み付き総和Recipeは、旧版との再現互換のため数値コスト8を超えても受け付けます。保存Recipeの再現でも全項のLean検証は実施します。任意の構成や全パラメータについて、参照版の品質判定・採点との完全互換を主張するものではありません。

## 登録した数学的な構成

学校の添字は1から、Lean内部の添字は0からです。現在は有理数値の数列を扱います。連立は2数列です。係数の範囲は系統ごとに検証し、基本の公比・異なる特性根は2〜5の整数に限定します。指数の3項間では底は2または3、指数パラメータは小さい非負整数です。部分和の境界を満たすため、正規化した部分和の一部では負の振幅も使用します。

以下の「種類」は、係数の違いを数えず、登録された構成を数えたものです。

|系統ID|構成・制限|種類|Lv|
|---|---|---:|---|
|`arithmetic`|等差数列|1|1|
|`geometric`|等比数列|1|1|
|`scaled_constant`|一般項`c n`となる階比|1|2|
|`factorial_ratio`|階比`r n`、一般項`c r^(n−1)(n−1)!`|1|2|
|`second_order`|異なる2根の定数係数3項間|1|3|
|`reciprocal_affine`|逆数が等差となる一次分数|1|4|
|`weighted_sum`|倍率`n`で正規化する重み付き総和|1|5|
|`affine`|不動点を引く2項間|1|2|
|`shifted_scaled`|定数移動と12倍率：6基本倍率と各逆数|12|3・4|
|`scaled_affine`|倍率と不動点。直接倍率は`n`、`n+1`、`2n+1`、逆数倍率は6種類|9|4|
|`reciprocal_scaled`|逆数と倍率。倍率は`scaled_affine`と同じ9種類|9|5|
|`polynomial_forcing`|一次式の付加項と一次式の特解|1|3|

|`mobius`|不動点との差を逆数にする一次分数|1|4|
|`scaled_second_order`|倍率`n`、`n+1`、`2n+1`と異なる2根の3項間|3|4|

|`forced_second`|定数項を含む、異なる2根の3項間|1|4|

|`ratio_power`|一般項の指数が`n(n−1)/2`、`n²−1`、`(n+1)n(n−1)/6`|3|3・4|
|`multiplicative_second`|積の3項間。指数の二階差が定数、`n`、`2n+1`に比例|3|5|
|`coupled_symmetric`|対称な連立を和と差で分離|1|3|
|`coupled_weighted`|重み2または3の一次結合で分離する連立|1|3|
|`coupled_scaled`|倍率`n`、`n+1`、`2n+1`で正規化する連立|3|4|
|`coupled_forced`|定数または一次式の付加項を含む連立|2|3・5|
|合計||75||

6基本倍率は`n`、`n+1`、`n²`、`n(n+1)`、`n(n+2)`、`2n+1`です。倍率を含む系統がすべて12種類に対応するわけではありません。例えば`scaled_affine`と`reciprocal_scaled`の直接二次倍率は、付加項の係数次数の上限を超えるため登録していません。正規化した部分和は`S₀=0`の境界を満たす構成だけを採用します。

`multiplicative_second`の対数は解法説明に使用します。Leanでは対応する自然数指数の冪関係、正値性、非零条件と一意性を証明します。実数値の任意の数列や実数対数の一般論への拡張は含めません。

## 受入確認と計測の範囲

通常のRustテストは厳密な初期値・漸化式、登録プロファイル、Recipe再現、版・接続の改変拒否、内容ハッシュ、一般項を隠した前向きの解法検出、未完成の証明・独自公理の拒否、解答を閉じたTeXへの一般項の漏出を確認します。実際のLean検証は準備後に`cargo test --test lean -- --ignored`と、各拡張モジュールの無視指定テストで行います。有限項の照合は移植の検査であり、全項の証明の代わりには使用しません。

開発専用の`scripts/check-reference.py`は、固定した参照版v0.7.0と、初期条件、20項の厳密な一般項、解答を仮定しない3通りの入力値での各漸化式、教育スコアを照合します。`examples/export-fixtures.rs`は75種類の登録構成ごとに複数の係数例を出力します。参照版Pythonはアプリの実行には使いません。実施済みの結果は[検証記録](validation.md)に記載します。

候補200件、候補探索10秒、Lean60秒、要求全体120秒、Lean候補2件は設計書の提案値を採用した初期値です。コマンドラインで変更できます。速度の保証値ではありません。ベンチマークは準備済み環境での直列50問を対象に、中央値・95パーセンタイル・最大値と失敗数を記録します。初回取得と共通コンパイルは含めません。TeXはpLaTeX＋dvipdfmx向けに出力し、PDFの組版は利用者環境で行います。

## 残る設計項目

登録プロファイル以外の倍率・付加項、自由なブロック合成と一般的な正規化、重根や広い係数範囲、実数値の数列、複数解法と別解、Lean常駐化・並列化は今後の拡張です。Linuxで動作確認し、macOS・Windowsネイティブ、配布インストーラーは実機で未確認です。

Lv4・Lv5にも複数の非分数系統を追加しました。直近40問の窓幅と重み補正は暫定値であり、「非分数3種類以上」「逆数型40%以下」という多様性目標は、出題集合を測定して評価する必要があります。生成可能な係数範囲は有限で、旧版の242問という件数は上限に使用しません。

探索の段階別時間・除外理由別採用率、初回準備時間、プロセス別のピークメモリとCPU、異なる利用者PCの性能は追加の測定が必要です。pLaTeXによるPDF組版の実機検証も別に必要です。
